## Job

<TypeTable
  type={{
    job_id: { type: 'string', description: '12-character hex id', required: true },
    status: { type: "'queued' | 'running' | 'done' | 'failed'", required: true },
    stage: { type: 'string | null', description: 'fetching, chunking, chunked, analyzing, indexing, aggregating, complete' },
    detail: { type: 'Record<string, unknown>', description: 'Stage context, e.g. { chunks: 39 }' },
    result: { type: 'IngestResult | AggregateResult | null', description: 'Populated once status is done' },
    error: { type: 'string | null', description: '"TypeName: message" when failed' },
    created_at: { type: 'string', description: 'ISO 8601, UTC, second precision' },
    updated_at: { type: 'string' },
  }}
/>

## IngestResult

<TypeTable
  type={{
    video_id: { type: 'string', description: 'sha1(bytes)[:16]', required: true },
    video_url: { type: 'string', description: 'Public Storage URL of the mp4', required: true },
    poster_url: { type: 'string | null', description: 'Single extracted frame; null if extraction failed' },
    storage_path: { type: 'string', description: '{video_id}/{filename} in the bucket' },
    filename: { type: 'string' },
    duration: { type: 'number | null', description: 'Seconds, from the container' },
    size_bytes: { type: 'number | null' },
    chunk_config: { type: 'string', description: 'e.g. "audio_video:5-20" or "interval:10"' },
    chunks: { type: 'number', description: 'How many chunks were produced' },
    analyzers: { type: 'string[]', description: 'Every analyzer with output on this video' },
    indexed: { type: 'Record<string, number>', description: 'Vectors written per analyzer. Zero is normal for a silent video' },
    aggregated: { type: '{ ran?, reused?, aggregates?, error? }', description: 'Result of the aggregation stage' },
  }}
/>

## SearchResult

Which fields are populated depends on `detail`.

<TypeTable
  type={{
    video_id: { type: 'string', required: true },
    chunk_id: { type: 'number', description: 'Index within its video only', required: true },
    start: { type: 'number', description: 'Seconds', required: true },
    end: { type: 'number', description: 'Seconds', required: true },
    timecode: { type: 'string', description: 'e.g. "1:17.80-1:23.80"', required: true },
    score: { type: 'number', description: 'Cosine similarity, 0–1', required: true },
    snippet: { type: 'string', description: 'detail=minimal only — first 180 characters' },
    video_url: { type: 'string', description: 'detail=standard and above' },
    description: { type: 'string' },
    people: { type: 'string[]' },
    objects: { type: 'string[]' },
    actions: { type: 'string[]' },
    tags: { type: 'string[]' },
    speakers: { type: 'string[]' },
    people_count: { type: 'number | null' },
    turns: { type: 'SpeakerTurn[]' },
    text: { type: 'string', description: 'detail=full only — the text that was embedded' },
    persons: { type: 'object[]', description: 'detail=full only' },
    detections: { type: 'object[]', description: 'detail=full only' },
    texts: { type: '{ text, context? }[]', description: 'detail=full only' },
  }}
/>

## Chunk

One chunk with whatever each analyzer produced for it, merged onto the same object.

<TypeTable
  type={{
    chunk_id: { type: 'number', required: true },
    start: { type: 'number', required: true },
    end: { type: 'number', required: true },
    timecode: { type: 'string', required: true },
    default_video: { type: '{ description, setting, people[], objects[], actions[], tags[] }' },
    transcript: { type: '{ text }' },
    diarization: { type: '{ turns: SpeakerTurn[], speakers: string[] }' },
    ocr: { type: '{ texts: { text, context }[], summary }' },
    people: { type: '{ people: object[], people_count: number }' },
    object_detection: { type: '{ detections: { object, description, context }[], objects: string[] }' },
  }}
/>

<Callout type="info">
  Only the analyzers that ran appear as keys. Checking `"people" in chunk` is the right way to ask
  whether that pass produced anything for this moment.
</Callout>
